# Hans Jonas – L'etica della responsabilità

Presentazione interattiva di 22 slide per le classi quinte del liceo, in preparazione dell'Esame di Stato.

**Contenuti:** la tecnica e il nuovo agire umano, l'etica tradizionale, il nuovo imperativo, il confronto con Kant, il fondamento ontologico, l'euristica della paura, il principio di precauzione, la critica all'utopia, il Dio dopo Auschwitz, critiche e collegamenti per la Maturità.

**Uso:** scorrere con le frecce ← → della tastiera, con i pulsanti o con lo swipe su smartphone.

## Pubblicazione su GitHub Pages
1. Crea un nuovo repository su GitHub.
2. Carica `index.html`, `README.md` e `.nojekyll`.
3. Vai in *Settings → Pages*, scegli *Deploy from a branch*, branch `main`, cartella `/ (root)`.
4. Dopo qualche minuto la presentazione sarà online all'indirizzo indicato in *Pages*.
